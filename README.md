# 多人記帳拆帳 (記帳專業版 - PWA 行動版)

專為手機輸入設計的親子與多人團體分帳記帳 Web 軟體，支援大人/小孩設定、夫妻檔歸併、按代付者直連歸還方案，並提供 **雙模式拆帳計算**、**GPS 定位店家**、**多相片帳單儲存**與 **Google Sheets 雲端備份**等專業功能。

## 🌟 專業版 (Pro) 升級功能

1. **📍 GPS 周邊店家抓取**
   * 在新增消費紀錄時，可一鍵抓取目前手機 GPS 位置。
   * 串接 OpenStreetMap 搜尋周邊 150 公尺內之餐廳、商店、住宿與景點，一鍵填入消費項目名稱，省去手動輸入繁瑣！
2. **📸 帳單照片本機存檔 (無限制張數)**
   * 支援直接調用手機相機拍攝帳單明細，或自相簿上傳多張照片。
   * **技術突破**：採用瀏覽器高容量的 **IndexedDB** 儲存二進位照片資料，擺脫傳統 LocalStorage 的 5MB 空間限制，不需伺服器便能享受安全、高速的離線相片檢視與放大。
3. **📊 Google Sheets 雲端試算表備份**
   * 提供專門的 Google Apps Script (GAS) 部署範本。
   * 無需託管 OAuth 驗證，保障 100% 個人資料隱私。一鍵將「成員清單」、「消費明細」與「家庭收支/轉帳結算」完整同步寫入您的個人 Google 試算表中，方便後續保存、列印與二次計算！
4. **⚡ 雙模式拆帳計算 (直連清償 vs 最佳化簡化)**
   * **直連清償 (預設)**：誰幫您代付就直接還給誰。每筆債務關係透明、可追溯，最適合由多個獨立家庭/伴侶組成的團體出遊。
   * **最佳化簡化**：自動將所有家庭的淨收支進行多對多配對並互相抵銷（例如：A 欠 B $50，B 欠 C $50 ➔ 簡化為 A 直接還給 C $50），將轉帳筆數降到最少，省去親友群組多餘的轉帳步驟！
   * **LINE 分帳與備份整合**：LINE 分帳訊息會根據當下選取的計算模式自動生成。此外，Google Sheets 一鍵雲端備份時，也會在工作表中同時並列直連轉帳與最佳化轉帳兩組方案供隨時對照！

## 🎯 設計精神
本專案的開發初衷是為了解決多人/多家庭共同出遊時，繁瑣且不直觀的拆帳痛點：

1. **誰幫我刷卡，我就直接還給誰 (直連歸還)**
   * **傳統痛點**：市面上的拆帳 App (如 Splitwise) 通常會透過演算法進行「債務最簡化」，將債務移轉給第三方（例如：A 欠 B $500，B 欠 C $500 ➔ 簡化為 A 直接轉給 C）。但在真實親友社交中，這常導致「我不知道為什麼要轉錢給 C」或「我明明是欠 B 錢，卻要轉給不熟的 C」的尷尬情況。
   * **本專案解法**：堅持「直連歸還」。所有的淨轉帳關係，都嚴格建立在「實際代付者」與「實際受益人」之間。債務關係完全可追溯，清清楚楚。
2. **以「家庭/戶頭」為結算單位**
   * 出遊時，夫妻通常財務合併，小孩的費用也由父母支付。本專案支援將成員歸併為同一個「家庭戶頭」，自動抵銷家庭內部的代付，並合併對外的應收與應付帳款，將結算流程降到最簡。
3. **無伺服器、零隱私洩漏、極速體驗**
   * 純前端運作，免註冊、免登入、無後端資料庫，100% 離線可用。您的記帳資料永遠只留在您自己的手機裡，安全無虞。

## 📖 使用方式

### 步驟 1：建立行程
在「資料管理」分頁，設定本次的行程名稱（例如：`2026 墾丁三日遊`），此名稱會同步顯示在 LINE 結算報告的標題中。

### 步驟 2：成員與家庭關係設定
在「成員管理」分頁，新增所有參與行程的人員：
*   **大人與小孩**：可設定成員類型。
*   **配偶設定**：若為夫妻或伴侶，可將雙方互設為「配偶」，系統會自動將兩人合併為同一個結算戶頭。
*   **父母設定**：將小孩的家長設為其「父母」，小孩產生的帳單會自動併入家長的戶頭中結算。

### 步驟 3：記錄每筆消費
在「消費清單」分頁，點擊「新增消費」並填入：
*   **代付者**：這筆錢是由誰刷卡或付現。
*   **分攤成員（受益人）**：誰參與了這項活動或消費。
*   **多種拆帳模式**：
    *   **均分**：所有人平均分攤。
    *   **小孩固定金額，大人平分**（特別實用 🌟）：可指定小孩每人只收固定清潔費/床位費（例如 $200），剩餘的餐費或住宿費由大人平分。
    *   **按權重分攤**：可自訂每人的分攤權重（例如大人權重 1.0，小孩權重 0.5）。
    *   **自訂金額**：精確輸入每個人各自花費的金額。

### 步驟 4：一鍵導出與 LINE 分享
在「結算報告」分頁，會即時顯示：
1.  各家庭的代付、消費與應收/應付淨額。
2.  **雙模式轉帳方案切換**：可點擊按鈕自由在「直連清償方案」與「最佳化簡化方案」之間切換，即時計算結果。
3.  點擊「**複製 LINE 結算報告**」，系統會自動根據您目前選取的計算模式，複製對應的清償文字報告，讓您直接貼到 LINE 群組通知大家付款。

## ⚠️ 使用限制與注意事項

由於本專案採用純前端 PWA 技術以保障隱私和離線體驗，因此有以下使用限制：

1.  **資料儲存在瀏覽器快取中**
    *   所有資料均存放於手機瀏覽器的 `localStorage` 中。**清除瀏覽器快取、清除瀏覽紀錄或使用「無痕/私密瀏覽」模式**，皆會導致記帳資料遺失。
    *   *建議：在行程進行中或結束時，可至「資料管理」點擊「導出備份 (JSON)」，將檔案備份至手機檔案夾中，以防意外遺失。*
2.  **不支援多機同步編輯**
    *   本專案無雲端資料庫，因此**無法多台手機同時連線、共同編輯同一份帳本**。
    *   *建議：旅程中指定一位「主記帳員」負責用手機記錄所有帳目；或者將帳本導出 JSON 傳給另一人導入接力記帳。*
3.  **iOS PWA 快取獨立性**
    *   在 iPhone 上使用 Safari 瀏覽網頁時的資料，與透過「加入主畫面」後開啟的 PWA 桌面上 App 的資料**是各自獨立、互不相通的**。
    *   *建議：請統一在其中一種管道（建議直接點擊桌面上的 PWA App）進行記帳，避免資料錯亂。*
